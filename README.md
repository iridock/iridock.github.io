# IriDock ボーダー予想

https://iridock.github.io/

デイリーランクスコアのボーダー（+2・+4・+6）の予想と、直近1年の実際のボーダーを見るサイトです。

- 予想は過去の記録から計算した見当で、外れることがあります。
- データ（`data/`）は毎日自動で更新しています。このリポジトリは自動で書き換わるので、プルリクエストは受け付けていません。
- アクセス数を数えるために [GoatCounter](https://www.goatcounter.com/) を使っています（Cookie は使いません）。
- 書体は、iPhone・Mac では端末の書体を使います。ほかの端末向けに [Inter](https://github.com/rsms/inter) と [Noto Sans JP](https://github.com/notofonts/noto-cjk) を、サイトで使う文字だけに絞って同梱しています（SIL Open Font License 1.1。許諾の文は `fonts/` にあります）。
